# tldr-rss

Read [TLDR](https://tldr.tech) newsletters in your RSS reader, with one item
per article, original summaries, and direct links to the stories.

## Why?

TLDR's own feeds group articles into whole newsletter issues. These feeds
let you read and mark each story individually, with sponsors removed and
shared stories deduplicated across newsletters.

## How to use it

Copy this URL into your RSS reader's **Add feed** or **Subscribe** option:

```
https://nickrwann.github.io/tldr-rss/all.xml
```

For fewer stories, copy a topic bundle or individual newsletter's link below.
Choose one bundle to avoid overlap between subscriptions.

Feeds refresh every three hours and include the last 14 days of articles.
No new weekend issue is needed—recent stories remain available.
